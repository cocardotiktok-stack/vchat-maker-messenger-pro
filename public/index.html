Cómo configurar las claves (Render)

  1. Entra a tu servicio en dashboard.render.com
  2. Ve a la pestaña Environment
  3. Añade estas variables:
    • OPENAI_API_KEY → tu clave de OpenAI (empieza por sk-)
    • ELEVENLABS_API_KEY → tu clave de ElevenLabs
  4. Guarda y espera a que el servicio se reinicie

Las claves nunca se guardan en el navegador ni se envían a terceros. Solo el servidor las usa.

Cómo obtener las claves

  • OpenAI: platform.openai.com/api-keys (necesitas cuenta y créditos)
  • ElevenLabs: elevenlabs.io → Profile → API Key

Límites del plan gratuito de Render

  • El servicio se suspende tras ~15 min de inactividad (el primer acceso después puede tardar 30-60 s)
  • Memoria limitada: videos muy largos o con muchos mensajes pueden fallar
  • Archivos temporales se borran periódicamente
